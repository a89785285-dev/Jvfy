VANTA CODE 🚀

A Modern Android IDE — Built for Developers, Designed for Productivity

<p align="center">
  <strong>Code. Create. Execute. Build.</strong>
</p>VANTA CODE is an Android development environment designed to bring a modern coding experience directly to your smartphone.

Built with Kotlin and Jetpack Compose, VANTA CODE aims to make mobile programming more accessible through a clean interface, practical development tools, and a growing collection of language support.

Our vision is to create a powerful mobile IDE inspired by professional desktop development environments while maintaining the simplicity and flexibility of Android.

---

✨ Core Features

- Modern Dark Interface — A sleek dark-themed development environment with VANTA branding.
- Code Editor — Write and edit source code with line numbers and a programming-focused layout.
- JavaScript Execution — Execute JavaScript code using the embedded Rhino engine.
- Console Output — View execution results and error messages directly inside the application.
- File Management — Open existing source files and save your work to your device.
- Language Templates — Start projects with templates for multiple programming languages.
- Project Workspace — Dedicated sections for editing, projects, and settings.
- Android Native Experience — Built using Kotlin and Jetpack Compose.

🚀 Getting Started

Requirements

- Android Studio
- JDK 17
- Android SDK 35
- Gradle 8.9 or compatible Gradle installation

Build from Source

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_URL

2. Open the project in Android Studio.

3. Allow Gradle to synchronize dependencies.

4. Select the "app" run configuration.

5. Build and run the application.

⚙️ Automated APK Build

This repository includes a GitHub Actions workflow for building a debug APK.

To use it:

1. Push the project to GitHub.
2. Open the Actions tab.
3. Select Build VANTA CODE APK.
4. Run the workflow.
5. Download the generated APK from the workflow artifacts after a successful build.

📌 Development Status

Current Stage: Foundation Build — v1.0.0

VANTA CODE is an actively evolving project. Some languages currently provide editor templates only, while JavaScript execution is implemented.

The project is not yet a complete replacement for desktop IDEs or established Android coding applications.
